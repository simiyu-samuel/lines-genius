# 🚀 Lines Genius

**Lines Genius** is a sleek, modern web app that generates creative, catchy, and high-impact lines — from business taglines and social media bios to marketing slogans, ad lines, quotes, and captions. Built with React + TypeScript + TailwindCSS, it delivers a futuristic experience powered by AI.

---

## 🌟 Features

- 🔮 Generate catchy lines for:
  - Business taglines
  - Social media bios (Instagram, TikTok, Twitter)
  - Captions & quotes
  - Ad slogans & marketing phrases
- 🎨 Stunning neon-themed UI
- 🌗 Light/Dark mode toggle with animations
- 💾 Save generated lines (local storage)
- ⚡ Built with:
  - React + TypeScript
  - TailwindCSS
  - Framer Motion
  - React Router
- 📱 Fully responsive and mobile-friendly
